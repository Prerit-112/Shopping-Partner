How much each dimension should influence the final verdict and reasoning (1 = lowest, 5 = highest). The agent spends more research effort on higher-weight areas and explains trade-offs using these weights.

LLM debug logs

Each research or follow-up run appends a detailed trace (metadata, request/response summaries, token usage when provided) to local storage. API keys are never written to these logs.
